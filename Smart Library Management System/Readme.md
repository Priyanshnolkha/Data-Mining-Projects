# 📚 Smart Library Management

## Overview
An interactive Data Mining and Streamlit-based application developed to analyze student library usage patterns, identify behavioural trends, and generate actionable recommendations for improving library services.

## Tools Used
- Python
- Streamlit
- Pandas
- Scikit-learn
- MLxtend
- Matplotlib
- Microsoft Excel
- Power BI

## Dataset
- Library Management Dataset
- 500 student records
- Includes visit frequency, books borrowed, digital resources accessed, reading duration, preferred genre, peak library hour, and reason for visit.

## Data Mining Techniques
- K-Means Clustering
- Apriori Association Rule Mining
- Recommendation System

## Dashboard Features
- Total Students KPI
- Total Books Borrowed
- Digital Resources Accessed
- Average Reading Duration
- Popular Genres
- Peak Library Hours
- Reasons for Library Visits
- Reading Trends
- Books vs Digital Resource Usage
- Interactive Data Analysis

## Key Insights
- Analyzes student library usage patterns.
- Identifies different student usage segments using K-Means.
- Discovers relationships between genre, visit reason, and peak hours using Apriori.
- Provides personalized reading and digital-resource recommendations.
- Identifies high-demand genres for new-book purchase decisions.
- Provides peak-hour recommendations for better seating and staff planning.
